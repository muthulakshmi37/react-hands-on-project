# React Student Profile Hands-On

A beginner-friendly React project created to practice **Props and State** in React.

## 🚀 Features

### 1. Student Profile Using Props
- Displays student name
- Roll number
- Course
- College
- Uses React Props

### 2. Student Marks Using Props + State
- Displays student name and subject using Props
- Stores marks using React State
- Increase Marks button
- Decrease Marks button
- Marks are maintained between 0 and 100

### 3. Login Form Using State
- Username input
- Password input
- Uses React State to store form values
- Displays login success message when both fields are entered
- Displays an error message when fields are empty

## 🛠️ Technologies Used

- React
- JavaScript
- JSX
- Vite
- HTML
- CSS
